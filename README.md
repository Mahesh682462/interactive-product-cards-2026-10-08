This project showcases a responsive grid of product cards with interactive hover effects and a simulated loading animation. It demonstrates modern CSS layout, transitions, and a basic JavaScript mechanism to control UI state.

**Features:**
- Responsive CSS Grid layout for product cards.
- Smooth hover animations (scale, shadow, text reveal).
- CSS-only spinner loader.
- Simple JavaScript to simulate content loading.

**How to Run:**
1.  Save all files (`index.html`, `style.css`, `script.js`) into the same directory.
2.  Open `index.html` in your web browser.

Observe the loading spinner, and then the product cards will appear, ready for interaction.
